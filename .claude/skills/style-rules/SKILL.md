# Règles CSS/design TSM (condensé)

Source de vérité : `tsm-frontend/frontend/src/styles/STYLE.md`. Ce condensé suffit pour des retouches ; **gros chantier design (nouvelle page, nouveau thème, refonte) → lire STYLE.md en entier.**

## Règles d'or (non négociables)
1. **Aucune couleur en dur** — tokens `var(--…)` de `variables.css` + `color-mix()` pour les variantes. Exception assumée : `components/imageTemplates/` (export PNG, couleurs fixes, classes `.imgst-`).
2. Thème uniquement via `body[data-theme]` / `body[data-color-scheme]` posés par App.jsx — jamais de manipulation directe ailleurs.
3. **CSS pur** : pas de framework, préprocesseur, ni CSS-in-JS. Fichier CSS importé par son composant propriétaire ; le global passe par `globals.css` (ordre d'import important).
4. **Réutiliser avant de créer** (voir modules ci-dessous).
5. Tout nouveau style doit marcher en **light + dark sur les 16 thèmes** (les tokens le garantissent gratuitement ; override dark manuel seulement pour un fond en dur justifié).
6. Mobile obligatoire : desktop-first, breakpoints standard **900 / 700-640 / 600 / 480-360** px. Pas de scroll horizontal au niveau page (tableaux larges → conteneur `overflow-x:auto`). Inputs ≥16px sur mobile (anti-zoom iOS), cibles tactiles ≥36px.

## Nommage & organisation
- Classes kebab-case **préfixées par feature** : `landing-`, `adm-`, `imgstudio-`, `imgst-`, etc.
- Sous-dossiers `ttpd/` et `showgirl/` = mondes séparés, ne pas y importer les conventions globales.

## Look & feel
- Glassmorphism (surfaces translucides + `--glass-blur`), police **Inter** partout hors titres ; décoratives hors système de titres : TT Modernoir (Topbar), ACsteelfish (`@font-face` dans `variables.css`) — **pas de nouvelle font** sans demande explicite.
- **Titres de section thémés** (`--album-title-font`) : chaque thème force sa propre police décorative (10 Google Fonts chargées dans `index.html` — Archivo, Bebas Neue, Cormorant Garamond, DM Sans, IM Fell DW Pica, Libre Caslon Text, Permanent Marker, Satisfy, Style Script, UnifrakturMaguntia) sur une liste fixe d'une trentaine de sélecteurs `h2`/`.xxx-title` dans `themes.css` (`body[data-theme^="theme-"] :is(...)`, malgré le nom "album-title" ça couvre tous les titres de section). Nouveau titre de section à thémer → l'ajouter à cette liste, pas de règle éparpillée. Détail : `STYLE.md` §5.
- Or = rang #1 (`--gold-1/2/3`) ; deltas : vert hausse / rouge baisse / NEW / RE ; hovers courts.

## Thèmes
- Ajouter un thème = **4 endroits** : bloc light + bloc dark dans `themes.css`, entrée `ALL_THEME_OPTIONS` dans `utils/anniversaries.js`, allow-list `THEMES` dans `api/routes/site_settings.py`. **+ 1 si nouvelle police de titre** : `<link>` Google Fonts dans `index.html`.
- `theme-custom` = injecté au runtime (`utils/customTheme.js`), jamais statique. ⚠️ Piège de cascade : le bloc light injecté arrive après le scaffold dark de `variables.css` à spécificité égale → le bloc dark injecté doit redéfinir **tous** les tokens.

## Modules partagés à réutiliser (ne pas dupliquer)
- Public : `.page`, `.section-card`, `.stat-card`, `.ranking-table`, `.song-row-card`, `.delta`, `.table-wrap`, `.toolbar`, `.sort-menu`, `.milestone-chip`, `.focus-overlay` ; composants `RankChange`, `Sparkline`, `RegionFlag` (drapeau pays via flagcdn ; `il`→drapeau Palestine `ps`, `global`→globe), `ErasStripHeader` (bande des 12 portraits dans l'ordre des albums debut→Showgirl, préfixe `eras-strip-`, photos `public/eras-tour-hero/` — `panel-12` Showgirl est un composite teinté via `scripts/build_showgirl_panel.py` ; image composée `public/headers/all-eras.jpg` via `scripts/build_eras_strip.py`).
- Liste de `<SongRow>` : scope `.streams-songs-wrap` (Streams.css) = grid desktop + cartes `.song-row-mobile` ≤600px automatiques (SongRow rend les 2 DOM). Utilisé par Streams, SongDetail streams (`sgd-`, `SongDetail.css`) et AlbumDetail (`albd-`, `AlbumDetail.css`). Jamais de layout mobile maison en `::before`.
- Carte mobile "Marquee" (≤700px) : visuel de `.song-row-mobile*` défini **une fois** en haut de `Streams.css` (cover 70px, padding carte 11px, rang badgé sur la pochette sans #1 spécial, daily en Bebas Neue, total micro-label — densité réduite le 2026-08-31, était cover 82px/padding 13px). Sous le daily, pilule(s) = classe `.song-row-mobile-daily-chip` **obligatoire sur chaque span** (CSS class-based depuis le 2026-08-31, plus de `:last-child` → un span sans la classe perd le style pilule, piège déjà vécu). Pattern 2-pilules (absolu + %) ajouté le 2026-08-31, modifiers `.positive`/`.negative`. **4 consommateurs JSX indépendants à garder en phase** : `SongRow.jsx` (Streams/SongDetail/AlbumDetail), `Streams.jsx` bloc `.streams-album-mobile-card` (widget Top Albums home, markup à la main, `row.streamChange`/`streamChangePct`), `Albums.jsx` page `/albums` (`.album-row-mobile-daily-chip`, `row.change`/`changePct`), `YouTube.jsx` (vues : `dailyChange`/`daily_change_pct`, 1 pilule neutre si `metric.isPeriod`). Le `.delta` de rang est `absolute` en coin haut-droite de la carte (`top:11px; right:11px`), `.delta.neutral` masqué ; best-day = étoile or + `.best-day-mobile-label` micro-capitales grises. Détail : `STYLE.md` §6.
- Cartes « Overall » Apple Music / iTunes (tableaux pays/rang) : sur téléphone (≤600px, `hooks/useMediaQuery.js` `PHONE_QUERY`) le découpage JS donne **2 colonnes** dès 2 lignes (`splitPlacementsIntoColumns(…, phone)` / `splitIntoColumns(…, phone)`), grille `repeat(2, minmax(0,1fr))`, nom de pays dans `.oct-country-name` (ellipsis), pas de colonne sticky. L'image partagée est rendue à 1280px quelle que soit l'écran : grille de capture `repeat(auto-fit, minmax(240px,1fr))`, jamais un `repeat(4)` fixe (laisserait la moitié vide avec 2 tables). En-tête iTunes (`.itunes-overall-header`) : pilules de stats sur leur propre ligne en mobile, sinon elles écrasent le titre à 0px.
- `ShareImageButton` : pas de `cacheBust` (re-téléchargeait chaque drapeau/pochette → 13s sur une carte 72 pays → iOS refusait `navigator.share`, bouton « mort » en silence) ; CSS des polices calculé une fois par page ; si iOS refuse le partage (geste trop ancien) le bouton passe en `.is-ready` et le tap suivant partage instantanément ; autre échec → téléchargement.
- Image partagée d'un tableau Apple Music (`AmTable`) : prop `shareLimit` (TS Top Songs = `TS_SHARE_TOP_N` = **top 20**) → lignes au-delà en `.am-share-overflow share-image-exclude` (masquées en capture + hors du clone, la page montre tout ; 630 lignes = 30-75s). En capture, chaque ligne-grille reprend `width:100%` et des pistes fixes (la règle mobile `width:max-content` faisait déborder chaque ligne à la largeur de son propre titre → colonnes désalignées). TS Top Songs capturé à 1480px (11 colonnes pays).
- Admin : primitives de `adminUI.jsx` + patterns `adm-` (→ skill `admin-work`).
- **Nav mobile** (≤900px) : bottom tab bar app-like — `BottomTabBar.jsx`/`.css` (Home/Charts/Players + "More" → bottom sheet `tabbar-sheet-*` pour Eras Gallery/Journalist Department). Top bar réduit à logo + contexte page + rangée d'icônes circulaires assorties `.nav-icon-btn` (Admin/About/Langue/Thème, 28px, même `color-mix`) + bannière CTA glitter en ligne 2 si promo admin active. `LanguagePicker.jsx` (bouton globe + panel `langpick-*`) remplace le `<select>` natif — panel ancré en `left` clampé au viewport (jamais `right`, ça le pousse hors écran si le bouton n'est pas tout à droite). Token `--tsm-tabbar-height` (0 desktop, ~58px+safe-area mobile) consommé par `Footer.css`/`tables.css` pour la clearance du bas de page — plus de footer disclaimer fixe (retiré, le texte légal vit sur `/about`).
- **Nav desktop** (≥901px, depuis 2026-09-18) : rail vertical fixe flottant sur le bord gauche (`Nav.css` — `.site-nav{position:fixed;left:0;width:88px}` + `.site-nav-inner` en `flex-direction:column`, carte arrondie/glass identique au style mobile). Icônes uniquement, jamais de label texte (`.nav-home-label`/`.nav-about-label`/`.site-nav-link-label` toujours `display:none` — le `title=` HTML fait office de tooltip). `LanguagePicker` (`.nav-lang-btn`) remplace aussi le `<select>` sur desktop ; le vieux `<select>`/`.site-nav-end` a été supprimé (pas juste caché). Icônes de section sans asset thème (Charts Gallery/Journalist/Players/Eras) → composants partagés `components/icons/SectionIcons.jsx` (`ChartsIcon`/`JournalistIcon`/`PlayersIcon`/`ErasIcon`/`HomeIcon`, prop `size`), réutilisés aussi par `LandingPage.jsx` — ne pas les redéfinir localement. **Toute page utilisant `.page` ou `.site-subnav-wrap` doit garder ce rail en tête** : les deux ont une règle `@media (min-width:901px){padding-left:calc(88px + 24px)}` (`base.css`/`Subnav.css`) puisque le rail est `position:fixed` donc hors du flux — un nouveau conteneur de page plein-écran qui n'hérite pas de `.page` doit reproduire cette clearance à la main.
